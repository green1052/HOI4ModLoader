# HOI4ModLoader

A C# plugin loader for Hearts of Iron IV, in the spirit of BepInEx. It changes no game files: everything happens in memory while the game runs.

The bundled plugins add quality-of-life features: research, focus and political power queues, auto construction, auto trade, air wings for field marshals and more.

## Requirements
- Hearts of Iron IV **1.19.3** (Steam, Windows 64-bit)
- [.NET 10 Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0)

## Installation
1. Install the [.NET 10 Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0).
2. Download the latest zip from [Releases](../../releases) and extract it.
3. Put `version.dll` and the `HOI4ModLoader` folder in the game folder (where `hoi4.exe` is).
   - Steam library → right-click Hearts of Iron IV → Manage → Browse local files
4. Start the game: the main menu's version label shows `HOI4ModLoader <version>` under the game version.

There is no mod to enable in the launcher. The few interface files the plugins change are built from your installed game each time it starts, so they keep up with game updates.

### Update
Automatic: at startup and every 6 hours the loader checks the latest GitHub release and installs a newer one in the background; it takes effect at the next start (the main menu version tooltip says when one is waiting). `[Update] CheckHours` in `HOI4ModLoader\config\HOI4ModLoader.cfg` sets the interval (0: only at startup, -1: off).

By hand: delete the old `HOI4ModLoader\plugins` folder first (plugins get merged or renamed between versions), then install as above. Your settings in `HOI4ModLoader\config` stay.

### Uninstall
Delete `version.dll` and the `HOI4ModLoader` folder from the game folder.

## Usage
- **Settings → Mods tab:** turn plugins on or off and change their settings. Hover a plugin for its description.
- **Main menu version label:** hover it for the list of loaded plugins.
- Each plugin's settings file is created in `HOI4ModLoader\config\` on first start.

## Plugins
| Plugin | What it does | Multiplayer |
|---|---|---|
| Queues | Research, focus, intelligence agency and political power queues | ✅ |
| AutoConstruction | Auto construction targets per building, auto supply, auto production | ✅ |
| AutoTrade | Imports resources you are short of, cuts imports you no longer need, draws your trade routes | ✅ |

### Queues
**Shift+click** to queue, again to unqueue. Queued items show their position as a gold numbered badge in front of their name (`[31]` and up past 30).
- **Research, national focus, intelligence agency upgrades:** the first queued item starts as soon as a slot is free.
  - Repeatable agency upgrades queue one more level per click (`1x3`).
  - Unqueueing a focus also unqueues the queued focuses that need it.
  - Items that can no longer start are dropped: researched techs, focuses already taken or shut out by a mutually exclusive focus, agency levels already done.
- **National spirits, laws, designers, advisors, decisions:** taken one at a time as soon as you have the political power; a full slot is replaced.
- Settings: the political power queue on/off.

### AutoConstruction
In the construction tab, **Shift+click** a building to raise its auto construction target by 1, **Ctrl+Shift+click** by 5, **Ctrl+click** to lower it by 1. The button shows how many are left as `+N`. Targets are kept per country for the whole session, across loads.
- What's missing is added to the end of the construction queue, one level per state (or province) so they are built at the same time.
- Location priority: core states, then higher infrastructure (lower infrastructure first when the building is infrastructure itself), then free building slots.
- **Auto supply:** where your divisions are low on supply, the right fix is queued: a saturated hub gets its railway to the capital upgraded (a naval base if the bottleneck is at sea), a cut-off hub a railway to the nearest connected one, and an area with no hub near a new supply hub (railway-connected provinces first). Setting: on/off.
- **Auto production:** military factories move one at a time from a line whose equipment has a big surplus to a line whose equipment is short (biggest shortage first), with the production screen's own command, at most a few per game day (nothing moves while paused). Land and air lines only; no line is created or emptied. Settings: on/off, what counts as surplus (% of need), cover days, factories moved per game day.

### AutoTrade
In the trade view, **Shift+click** a resource icon to turn auto trade on or off for it (`Auto` shows; kept per country for the session). A shortage is imported automatically, and an import that is no longer needed is cut back by whole steps (cancelled at 0), so the balance stays at the surplus you set.
- Seller priority: your subjects, your faction, then whoever can sell the most; trade influence breaks ties. Cuts go the other way round.
- Settings: allies first, and a surplus to keep (imports until the balance is at least that, not just 0).
- **Trade routes:** **Ctrl+Alt+C** draws your country's trade routes in gold, in any map mode: an arrow over the states a land route crosses and the strategic regions a sea route sails, for your imports and your exports alike.

### FrontLine
Front line micro a player does by hand, with the battle plan UI's own commands (multiplayer works). Divisions taken off a front go back onto it once their job is done; loading a save forgets them, and they stay where they are, off their battle plan. Divisions in combat are never picked (a defender can only retreat).
- **Rotation:** a worn-out division in contact with the enemy rests a few provinces back, where another of ours holds its province; at most a share of a front rests at once. A division short of equipment or manpower goes back after two weeks once its organisation has recovered.
- **Plugging:** a defence of ours that is being lost gets the nearest fresh division (resting, unassigned, or spare on a quiet part of a front).
- **Escape:** front divisions in a salient whose way back narrows to a neck of one or two provinces next to the enemy (salients up to 20 provinces) pull back through the neck, to safe ground behind it, before the pocket closes, if the enemy at the neck is strong enough to close it; one division stays in each province it held alone. **Breakout:** divisions already cut off (pockets up to 30 provinces, friendly lines within 6) attack together once a day at the enemy province that starts the shortest way out. Divisions on a landing with no port of its own (up to 12 provinces) go for the nearest enemy port first, since everything else reaches them only over the beach. Enemy divisions in a pocket (up to 12 provinces) or inside our ground are finished off first, by any fresh divisions around them (yours too, plan or not), as soon as they outgun them.
- **Attack:** empty enemy provinces next to the line are taken by a fresh division; surrounded enemy divisions are attacked only with at least as many fresh divisions as they have (more behind forts), and no more are sent while the first ones are still on their way or fighting. Best targets first: closing a pocket, then victory points, supply hubs, airfields and ports, then shortening the front; skipped are provinces our supply couldn't follow (unless they close a pocket) and worthless ones that lengthen the front by more than two provinces. **Assaults:** an enemy province the fresh divisions of our neighbouring provinces outgun twice over (`AttackOdds`; more behind forts, in rough ground or across a river) is attacked by all of them, each province keeping one; your divisions do this only on a battle plan that is running.
- **Fire brigade:** each front keeps one armored or motorized reserve per four line provinces (up to four, from up to twelve provinces away) on posts a province behind its line, off the battle plan (before a war, behind the border the AI drew a front on). Where the enemy breaks in (a province of ours lost in the last two days, a landing, enemy troops inside our lines), the nearest reserves counterattack with enough to win and then return to their post; a post the line moved away from is given up and its division goes back to its front.
- **Depth defence:** key line provinces (ports, victory points, river crossings, cities and mountains) get a second division a province behind them, from spare divisions of a front; it stays while the line holds there.
- **Shuffle:** a front that is losing (three provinces lost in two days or defences being lost, or facing twice its divisions) gets spare fresh divisions of quiet fronts in its most pressed provinces; they go back to their own front a day after the crisis. Meanwhile fresh divisions next to the crisis pin idle enemy stacks of one or two divisions with a cheap attack each (broken off when their organisation runs low), so those stay locked in combat and can't be shuffled in. A front that only faces an encircled pocket (the game splits one off with a share of the army) keeps twice the pocket's divisions, two at least; the rest go onto the army's main front.
- **Cordon** (defence in depth, with Plugging): ground of ours the enemy took in the last two days gets our empty provinces around it manned (the breach's shoulders and its tip, the most surrounded first, four a turn), so a breakthrough runs into a wall and its corridor stays narrow until its supply fails; the fire brigade and the cut at the salient's neck deal with what got in. A wall division holds its post while the breach next to it is the enemy's, a week at most.
- **Lure** (AI only, with ApplyToAI): an AI defence being lost is let go instead of plugged, to draw the attacker in, when both its shoulders are held and not being lost and two or more fresh mobile divisions stand within three provinces against at most twice as many attackers; AI Assist's encirclement then cuts the salient at its neck and the fire brigade counterattacks.
- **Battle plan keys:** Ctrl+Alt+E activates every battle plan of all your armies and army groups at once, Ctrl+Alt+H halts them (the same command the battle plan window's button posts).
- **Operations:** select an army (or divisions) and press **Ctrl+Alt+B** for a blitz: its fresh armored and motorized divisions break through the cheapest enemy sector (few divisions, no forts, open ground, no river) and push province by province toward a deep objective (victory points, a supply hub, many enemy divisions along the way), while its infantry holds the corridor behind them, one division per corridor province next to the enemy. Select two armies or an army group and press **Ctrl+Alt+P** for a pincer: two spearheads, one per wing, meet at the same objective behind the enemy; once the ring closes they go back and the infantry holds the ring for a week. Meanwhile fresh divisions of those armies support-attack idle enemy stacks next to the breakthrough and the corridor (one each, broken off when worn), so they are locked in combat and can't be moved into the gap. An operation ends when its objective is taken, the corridor is cut or a defence of it is being lost, or a wing's spearheads are all worn out (an organisation setting); the same key again cancels it. Its divisions then go back onto their battle plan (a fighting one once its battle is over). What it does is written to the log.
- **Apply to AI** (off by default, single player): AI countries get the same micro, with the same settings (not the keys or operations). AI Assist's own rotation, escape, reserves, second line and local attacks stand aside meanwhile, and its regrouping hooks leave these divisions alone; without AI Assist, the AI's regrouping may take them back.
- Settings: every threshold, each feature on/off.

### ArmySupport
- **Field marshals:** right-click a marshal's card with air wings or railway guns selected. In single player they are attached to the marshal (army group): his card gets air wing slots, his air wings support his armies' battles, and his railway guns take positions along all of his armies' divisions. In multiplayer they are spread over the marshal's armies instead. Setting: on/off.
- **Railway gun positioning (single player):** guns stay just behind the front line instead of on it, and never ship out by sea. The penalty and sea transfer are settings.
- **Airbase capacity:** with air wings selected, **Shift+right-click** an airbase to send only the wings that fit. The rest stay where they are.
- **Auto rebase:** a wing whose airbase reaches less than a share of its mission region (setting, 100% by default; 0 turns it off) flies to a usable airbase with room that reaches more, keeping its mission. Wings attached to an army are left to the game, which already does this.
- **Auto ground crews** (off by default): More Ground Crews (+10 % air efficiency in a region for command power, given back when turned off) goes on where your air wings fought hardest in the last two days (10+ planes lost and shot down where enemy planes are active), two regions at most, while command power stays above the reserve (setting, 50 by default), and off again where they stopped fighting for three days or command power falls under the reserve. Only the regions it turned on are turned off; one you turn off yourself is left alone for the rest of the game. Your own commands (multiplayer works).
- **Army organizer:** select divisions (drag a box, or click armies' and field marshals' cards) and press **Ctrl+Alt+G**. They are split into armies of at most the game's army size for a general (24 in vanilla), divisions standing near each other together; a whole army of at least half that size stays as it is. Each new army gets the best idle general, and all of them join the army group most of the divisions came from, or a new army group under the best idle field marshal. Armies without an idle general are left without one. The army list's own commands (multiplayer works). Setting: on/off.

### ChecksumPatcher
Keeps achievements available when mods change the checksum (Ironman already works with mods). Patched in memory only.

### Fonts
The game's text in a font you choose, with no font mod to make: pick an installed font from the Font setting's list (Settings → Mods → Fonts: its ▶ lists the installed fonts, a page at a time, to tick one), or set `Font` in `HOI4ModLoader\config\com.green1052.fonts.cfg` to the path of a `.ttf`/`.otf`/`.ttc` file, and restart the game.
- At startup every bitmap font of the game's language (`gfx\fonts\korean` for Korean, `gfx\fonts` for English, ...) is drawn anew with it by Windows: the same characters, line height and baseline, sized so its letters are as tall as the original's, as bold as the original, and with a dark outline and shadow as strong as the original's where it has one. Characters the font lacks keep the original glyph. Fonts whose texture is compressed (the map labels, a few others) stay as they are.
- The first start with new settings takes some seconds (Korean: about 10); the result is cached in `HOI4ModLoader\cache\fonts` until the settings or the game's fonts change.
- Settings: `HeaderFont` (titles; empty: the same font), `SizePercent` (glyph size in the same lines), `Typewriter` (redraw the typewriter fonts of documents and reports too; off by default).
- A font name Windows doesn't know is reported in the log, and the game's fonts stay.

### Reroll
HOI4 saves its random number generator's seed with the game, so reloading a save and doing the same thing replays the same battles and event outcomes. With Reroll, every game start and save load gets a fresh seed instead: combat, events' `random_list` and mean-time-to-happen events, and everything else drawn from the synced generator after the load come out differently. What was already decided before the save (an open event window, an event scheduled for a date) stays. Off in Ironman games unless `[Reroll] InIronman = True`. Single player only (every player's simulation must draw the same numbers).

### AiAssist
An add-on for [Sheep Mod](https://github.com/Sheep-of-Latrobe/sheeps-mod): it fixes vanilla AI logic that the mod's scripts can't reach, with no bonuses. It does nothing without Sheep Mod, and only in single player.
- **Hold the line:** at war, every province on the line keeps a defender and the front at least as many divisions as the enemy has across it (the theatre distribution only takes what is beyond a front's minimum, and that minimum is raised), no division on or right behind a line with enemy divisions near is strategically redeployed to another front, and against enemies that hold no port (they can't land) the AI keeps no coast and home garrisons; vanilla can ship a whole fighting front away (supply crisis, another front). The AI's regrouping can't take the last defender of a province next to enemy ground (troops there or not), the divisions walling in a pocket, a reserve, or a division that arrived in the last week (vanilla shuffles fresh arrivals back and forth). Free divisions walk back into empty line provinces — ports, victory points, river banks, cities and mountains first, key ground from further away — the same front's divisions first; one taken from another front is held there. A country with divisions to spare keeps reserves a province behind its line and a second division behind its key line provinces (depth defence); ready reserves counterattack break-ins near them (enemy troops inside our lines, ground lost in the last two days, a landing) and go back to their post (fire brigade). Divisions worn out by fighting (not by short supply) rest a few provinces back, a quarter of those around at most, and divisions in a salient whose way back is closing under an enemy at least as strong pull out before the pocket closes, as long as another division holds their province; neither happens where the AI outguns the enemy two to one. Rested divisions, and reserves the line moved away from, go back on their own order instead of being regrouped to a far front. A country short of divisions for its line doesn't start attacks and stops the running offensives of its thinly held fronts (advancing would widen the line and get the spearhead encircled), unless it outguns the enemy there two to one. These passes run on game time, so they keep up at any game speed.
- **Beach defence:** a naval landing is answered at once: free divisions near it wall the beachhead in and attack into it, instead of waiting for the front to collapse. A beachhead is ground the enemy took from the sea in the last ten days (even right next to its own coast), or a small enemy pocket on the coast.
- **Defensive postures** (needs Hold the line): an AI country facing a much stronger enemy (twice its share of power along the line, or 1.6x while it lost line provinces in the last week) gives up exposed ground and holds its *grad*: the most defensible short line between the enemy and its capital, found as a minimum cut through its own provinces (rivers, mountains, marsh, forests, hills, cities and forts in front, few directions to be attacked from). It is redrawn weekly, or one line back once the enemy breaks in. Divisions walk there and stay put (victory point cities get one more). The country starts no offensives or paradrops (landings still go); it attacks only fought-out enemy stacks next to the line, with two fresh divisions or more (reserves behind the grad too), while single divisions pin the enemy stacks that could come to their aid, and worn-out attackers break off. Once every enemy it fell back from stays under 80 % of its power for a week (a month after falling back at the earliest), its divisions go back on their orders; for a month after that, only twice its strength puts it back on a grad. Out of contact, the posture stays as it is. (Vanilla's own fallback lines are switched off by Sheep Mod's defines.)
- **Breakthrough axis:** local attacks keep to a breakthrough axis so the pushes don't zig-zag: while the AI's own armoured spearhead (the game's force concentration) attacks, the axis is where its path crosses the enemy line, and it moves forward with the spearhead; otherwise it is the front's thinnest enemy sector, held three days and moved on only once taken. Off the axis, the line only makes pinning attacks on enemy divisions next to it (a division under attack can't move except to retreat, so they can't shift into the breakthrough). Close air support backs battles on the axis first.
- **Strategic invasions:** naval invasions land where it hurts and can hold: thinly held coast near victory points, capitals, supply hubs, airfields and resources scores higher, beaches with enemy divisions nearby, forts or coastal bunkers lower (vanilla weighs only distance, ports and area priorities). A planned landing waits, a week at most, while the enemy divisions around its beach outnumber half the landing force.
- **Strategic paradrops:** the AI uses its paratroopers, which vanilla's AI never does (needs Breakthrough axis): up to four paradrop-capable divisions of an army of the axis' theatre fly from the airbase nearest the axis that can carry them onto an empty enemy province behind the line near the axis (victory points, supply hubs, airfields and pockets first), only when vanilla allows the drop (prepared, enough transport planes, air superiority on the route). A drop that hasn't gone in two weeks is given up. Sheep Mod's AI builds no paratroopers or transport planes, so drops are rare there; the log counts which check stopped them (no paratroopers, no source airbase, not ready, no target). With no axis drop, they drop behind a beachhead of the AI's own from the last ten days instead, from the airbase nearest it. Sheep Mod's AI builds few paratroopers and transport planes, so **Airborne units** (`[AI] AirborneUnits`, on by default) puts an AI strategy file in front of the game's own at startup: Germany, the UK, the US, Japan, the USSR and Italy research both, keep about 4% paratrooper divisions and build transport planes. Its values only add, so Sheep Mod's own aircraft bans (France, Italy and the USSR beside the UK/US, mass-mob and Chinese AIs, minors) still win. It changes the checksum: turn it off and restart to join a multiplayer game of players without it.
- **Attack targets:** local attacks go for pocket-closing targets first, then valuable ones (victory points, capitals, supply hubs, airfields, resources, empty or worn defences, dug-in defenders counting against a target), then ones that shorten the front, instead of a random pick. Next to a pocket of the AI's own divisions, the province that opens a corridor to it comes first (and breakouts from inside), ahead of pocket closing when at least as many of its divisions are trapped as the attack would cut off; vanilla has no relief logic. Fresh divisions also take empty enemy provinces next to the line, which vanilla's local attacks often skip.
- **Exploitation:** through a gap in the enemy line (empty enemy ground no enemy division covers), fresh mobile divisions drive up to four provinces deep to the most valuable province there (a capital, victory points, a supply hub, airfields), off their battle plan for a week; vanilla only takes the next province, so an empty capital behind a broken line stayed untaken.
- **Pincers** (needs Breakthrough axis): where the enemy masses divisions on the line (3+ in a province, twice the line's average), the axis becomes two arms, the thinnest enemy sector on each side 2-5 line provinces away, so the attacks close behind the mass; kept three days while both arms' targets are still the enemy's.
- **Feints** (needs Breakthrough axis): before a new main push, the AI's local attacks first hit, for 36 hours, the enemy line province with the most divisions at least five provinces away, so its reserves move there; the push waits meanwhile.
- **Offensive timing** (needs Hold the line): a battle plan's offensive starts once its divisions are ready, not while they average under 60% organisation nor while over 30% of them are still on their way to the line, nor while the enemy holds over 70% of the air over most of them, nor while most of them stand in mud (the weather manager's province mud flag).
- **Armor terrain:** armored and motorized divisions don't attack into terrain or across rivers that cripple them.
- **Supply-aware attacks:** local attacks skip provinces the attackers couldn't be supplied in once taken (setting: the supply share required); pocket-closing targets and the corridor to a pocket of ours are still taken.
- **Air retreat:** planes leave regions where the AI keeps losing the air war badly and go where it can win.
- **Bombing targets:** strategic bombers ask for twice the planes for enemy regions next to the land front and half for ones far behind it, which also rank lower; vanilla ignores how far a region is from the front.
- **Air training:** green air wings (under the second experience level) fly the training mission instead of going where nothing happens: at peace any wing the air AI sends on a mission, at war fighters it sends to patrol a land region no enemy plane flies in. At most half of a country's wings train at once; trained wings go back to the AI's missions. Vanilla trains only the wings it has no mission for, with the fuel left over, so its pilots learn in combat.
- **No fronts on bystanders' borders** (with Hold the line): an AI front whose border is at least 80 % held by countries that are no threat (and none of the rest at war with it or expected to be) wants no divisions and its orders are deleted, so the divisions go where a war is or may come. No threat: a country its own AI strategies mark as no target (a negative conquer, or ignore, befriend, alliance or protect; the scripts' antagonize is ideological and ignored), one in its faction, or a neutral too small to attack (in no faction, under a third of its land divisions: the Low Countries, Switzerland and Yugoslavia against Germany, not Poland). A country it expects a war with (the game's daily list: at war, a war goal or justification either way, a focus either way, a war preparation strategy, their factions and subjects), a guarantor of one, or a rival (a positive conquer or contain) always keeps its front. An ally's front overseas (its line all in the ally's ground, with no land route to the country's own) wants no divisions either and its orders are deleted, so none are shipped there (Germany had sent nine to Italian East Africa), unless the ally lost ground on that line in the last week and the country's own line is manned (an Afrika Korps when Italy needs one).
- **Stable leaders:** the AI no longer takes a general or field marshal from an army or army group he commands. Its daily leader choice let a group without a leader take the next best one even if he led another group, which then took him back the next day: every army changed its leader every day or two.
- **Army training:** AI armies with nothing to do train their divisions up to regular: at peace any army, at war armies holding no front (garrisons, reserves), while none of their divisions fights, stands next to enemy ground or is under 70 % strength; training stops by itself at regular. Vanilla stops every exercise once the country is at war (or has an occupied victory point, or prepares a war) and never looks at armies on no front.
- **Naval training and shore bombardment:** AI task forces no naval objective takes (vanilla puts them on hold and sends them to port) train at peace until their ships are regulars (vanilla stops training once world tension passes 50 %), and at war, if they have guns, go to the sea next to the country's coastal land battles within reach and hold there: ships on hold next to a battle bombard the enemy divisions in it.
- **Production lines:** a small factory cut to equipment whose lines run at 35 %+ efficiency is held for a while (setting: how many days), the factories coming off the smallest increases elsewhere; vanilla drains the last lines whatever their efficiency and restarts the factories at 10 %.
- **Refit priority:** reinforcements and new equipment go to front-line divisions (in combat or next to the enemy) before rear and garrison ones.
- **New divisions** (part of Hold the line): newly deployed divisions go where they are needed most first: the grad's holes, else the empty provinces of the threatened line, then the least held province of the most thinly held front, instead of wherever vanilla's theatre share-out sends them. They are left alone while they walk there.
- **Invasion escort** (part of Strategic invasions): the sea regions on a planned landing's route get twice the fighters the air AI wants there (100 at least) and twice the naval bombers. Vanilla's navy already has to win those regions before a landing sails, and its fleets already head there; its air AI never looks at the route.
- **Encirclement:** enemy salients are cut at their base instead of pushed head-on: where enemy ground bulges into the AI's line through a neck of one or two provinces and taking it cuts off 3+ enemy divisions for less than it costs, the local attacks and close air support of both flanks go for the neck until the pocket closes (a week at most).
- **Railway guns:** the AI's railway guns go to the armies on its breakthrough axis first and stay there.
- **Supply hubs:** where an AI country's divisions are low on supply, the railway from the hub feeding them to the capital is upgraded a level (one a week, the same hub's again after 60 days), cheap next to a hub. From 1941 on, where the divisions of an AI country with 60+ civilian factories starve with no hub within 3 provinces, it also builds one (weekly, two a month at most); a hub costs 20000, so earlier or poorer it doesn't. Vanilla's AI already upgrades and links existing hubs.
- **Ground crews:** the AI spends spare command power on More Ground Crews (+10 % air efficiency in a region; 20 command power, given back when turned off), which vanilla's AI never uses: every two days, in the regions where its air wings fought hardest in the last three days (10+ planes lost and shot down where enemy planes are active), two at most, while 50 command power is left after the cost. Off again where its wings stopped fighting for a week, or one a pass while command power is under 50.

## Multiplayer
- Other players see vanilla. Only interface files change, never the checksum, so players without the loader can join the same game.
- Plugins like the queues and auto construction send the same commands a player's clicks would, so they work as usual.
- Features that change game rules (field marshals holding air wings and railway guns, railway gun positioning, AiAssist) switch off in a multiplayer lobby and back on in single player. Field marshal assignment switches to spreading over the marshal's armies with vanilla commands instead.

## Performance: start-up
- **Prefetch:** each start records the files the game opens in its first two minutes (`HOI4ModLoader\cache\prefetch.txt`, about 19,000 files and 4 GB with Sheep Mod), and the next start reads that list on four threads from the exe's entry point, so they are in the system's file cache before the game asks for them. A cold start is mostly waiting on the disk (24 s warm against 62 s cold measured). An empty `HOI4ModLoader
o-prefetch` file turns it off.
- **Signature cache:** the loader's code lookups are saved per game exe (`HOI4ModLoader\cache\signatures-*.txt`): its own start went from about 4 s to 0.3 s.
- **Profiler:** an empty `HOI4ModLoader\profile-startup` file makes the next start write `HOI4ModLoader\startup-profile.txt` (150 s from the entry point); creating `HOI4ModLoader\profile-now` while the game runs profiles the next 60 s into `profile-<tick>.txt`. Every game thread is sampled with its call stack: per thread how much it ran, the hoi4.exe functions on running stacks (inclusive), and what the main thread waits in.

## Performance: mimalloc
On by default: the game's memory allocations use Microsoft's [mimalloc](https://github.com/microsoft/mimalloc) instead of the Windows heap. `[Performance] Mimalloc = False` in `HOI4ModLoader\config\HOI4ModLoader.cfg` turns it off (takes effect at the next start). The game sometimes reads memory it just freed, which the Windows heap tolerates; so small blocks are freed a little late (after the same thread's next 16384 frees), and the known case, targeted decisions, waits until the decision is done.

## Troubleshooting
- **".NET 10 Runtime (x64) not found" message:** install the .NET 10 Runtime (x64). The game still starts, without mods.
- **A plugin does nothing:** check `HOI4ModLoader\LogOutput.log`. Plugins don't load on game versions other than 1.19.3.
- **UI elements missing or broken:** other mods that replace the same interface files (settings window, main menu, construction tab, intelligence agency, army group card) can conflict; the loader's versions win.
- **Turning a plugin off:** use the Mods tab, or set `Enabled = False` in `config\<plugin id>.cfg`.
- **What do FrontLine and AI Assist do?** `[Debug] AiActionArrows = True` in `HOI4ModLoader\config\HOI4ModLoader.cfg` flashes an arrow on the map for a few seconds for each front line action they take (encirclements, breakouts, assaults, holes filled). Arrows show once the game has drawn one of its own (select a unit or open a map mode with arrows).
